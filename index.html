Things I've built

Smart Cursor

Hold a key, point at any word on your screen, and a local model explains it in the context of the paragraph around it. Every lookup lands in a SQLite glossary you build just by reading.

Qwen3 4B, 4-bit on MLX, running on an M4. The paragraph is prefetched into the prompt cache as you scroll, so only the term is new at hover time, and a 0.6B draft model does speculative decoding. The target is first token under 150 ms at p95.

Agent-Mark

An evaluation harness for agents you can't see inside. It records every tool call (name, arguments, result, latency, tokens) and scores the trace on task success, tool correctness, efficiency, latency and cost.

Task success is judged by an LLM; tool use is checked programmatically against each task's expected tools. Ships with adapters for Composio's open-source Trustclaw agent against a live Gmail inbox, and for Claude with Composio tools.

FlowGap

Reads a voice agent's call transcripts and finds what callers wanted that the flow has no node for: the calls that quietly end in a transfer to a human. Then it drafts a node for each gap.

An offline pipeline of MiniLM embeddings, UMAP and HDBSCAN to discover intents nobody listed, matched against the declared flow and shown in a React Flow dashboard. Gap intents come back at 90–100% purity.
